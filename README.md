# Glassmorphism Login Form

A responsive login form built with HTML & CSS, featuring a frosted-glass (glassmorphism) design over a full-screen background image.

## Features

- Full-screen background image
- Frosted-glass effect using `backdrop-filter: blur()`
- Semi-transparent login box with soft border
- Input focus states for better user feedback
- Responsive, centered layout using Flexbox

## Tech Stack

- HTML5
- CSS3 (Flexbox, `backdrop-filter`, pseudo-elements, `:focus`)
- Google Fonts (Open Sans)

## What I Learned

- Using `::before` pseudo-elements to create background layers separate from main content
- `backdrop-filter: blur()` for the glass effect
- Positioning full-screen backgrounds using `position: absolute` with `top: 0; left: 0;`
- Styling input fields on `:focus` for better user experience
